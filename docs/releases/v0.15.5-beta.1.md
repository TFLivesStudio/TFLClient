La carpeta de datos del perfil pasa a llamarse TFLClient, el visor de capturas en tamaño completo ya cubre toda la ventana con la barra lateral desplegada y se mejora la detección de la tarjeta gráfica en sesiones remotas.

**Canal:** Beta / prueba

> Versión de prueba: puede contener errores.

## Correcciones

- El visor de capturas en tamaño completo cubría solo parte de la ventana cuando la barra lateral de instancias estaba desplegada; el panel se pintaba por encima. Ahora el visor ocupa toda la ventana en ambos estados de la barra lateral.
- La carpeta de datos del perfil (instancias, ajustes, temas, skins) pasa de `.tflclient` a `.TFLClient` para coincidir con el nombre de marca que ya se muestra en toda la app. Las instalaciones existentes se migran automáticamente sin perder instancias ni ajustes.
- El panel "Estado del sistema" podía mostrar la GPU como no disponible en una sesión de Escritorio Remoto (RDP) aunque el equipo tuviera una tarjeta gráfica real instalada. Ahora se detecta y filtra el adaptador virtual de RDP para mostrar el hardware real cuando está disponible.

## Mantenimiento

- Se actualizan dependencias nativas transitivas (`cookie`, `url`) para resolver avisos de seguridad publicados a mediados de noviembre; no afectan a ninguna función visible.

## Compatibilidad y límites

- La corrección de GPU en sesiones RDP sigue el patrón documentado para esta limitación conocida de Windows; no se pudo verificar contra una sesión RDP real desde este entorno de desarrollo.
- Se investigó un reporte de etiquetas de instancia poco legibles en modo claro. No se encontró ni se reprodujo el problema con los datos disponibles; queda pendiente de una captura más específica antes de tocar código.
