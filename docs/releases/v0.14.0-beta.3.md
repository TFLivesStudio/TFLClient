Las escenas cinematográficas reciben nuevas imágenes y se amplía el catálogo de fondos de pantalla del launcher.

**Canal:** Beta / prueba · **Publicación original:** 2026-10-22 (UTC)

> Versión de prueba: puede contener errores.

## Novedades

- Arte renovado para las siete escenas, incluidas Cherry Night y Emerald Grotto.
- Treinta y seis fondos de pantalla añadidos en Ajustes → Apariencia → Fondo de pantalla.

## Compatibilidad y límites

- Diecisiete de estos fondos se retiran en 0.14.0-beta.6 al detectarse una resolución insuficiente para su uso a pantalla completa.
