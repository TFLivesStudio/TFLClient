Se incorpora una integración MCP local con aprobación por sesión y se renuevan las escenas con arte propio, atmósfera y vídeos locales a 720p.

**Canal:** Beta / prueba · **Publicación original:** 2026-10-22 (UTC)

> Versión de prueba: puede contener errores.

## Novedades

- Panel Integraciones para conectar asistentes compatibles mediante un auxiliar MCP local.
- Aprobación explícita de cada sesión, permisos por grupo de acciones y confirmación de operaciones críticas.
- Herramientas del asistente conectadas a los servicios del launcher para consultar y gestionar contenido autorizado.
- Cinco paisajes cinematográficos nuevos, con miniaturas y bucles de vídeo locales a 720p.

## Mejoras

- La atmósfera evita actualizaciones JavaScript por cada frame y respeta el modo Lite.
- Los cambios de escena y consola se sincronizan entre ventanas.
- Las instalaciones comparten bloqueos y controles de descarga con el launcher.

## Correcciones

- Se conservan la identidad de las copias de seguridad y las preferencias durante las migraciones.
- Se limitan los diagnósticos descomprimidos y se revisa la ocultación de marcadores de tokens.

## Compatibilidad y límites

- MCP es opcional y local: necesita el launcher abierto, el auxiliar configurado y un cliente compatible. Esta entrega no concede acceso automático a un asistente ni acredita certificación de proveedores externos.
