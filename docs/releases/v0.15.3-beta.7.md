Se corrige la preparación del arranque de Minecraft en macOS y la elección de Java 25 nativo para TFL Selection en equipos Apple Silicon.

**Canal:** Beta / prueba · **Publicación original:** 2026-11-13 (UTC)

> Versión de prueba: puede contener errores.

## Correcciones

- El comando de arranque añade «-XstartOnFirstThread» en macOS cuando todavía no está presente, para que la ventana del juego inicialice su entorno gráfico en el hilo principal.
- Java 25 utiliza la arquitectura nativa del equipo. En Apple Silicon evita seleccionar el Java x64 reservado para otras instancias antiguas.
- Se mantienen las reglas de compatibilidad de Java utilizadas por las instancias antiguas que no requieren Java 25.

## Al actualizar

- Vuelve a iniciar la instancia afectada desde Jugar. El launcher comprueba el Java necesario y lo descarga si falta.
