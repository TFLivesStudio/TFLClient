El avatar de las cuentas de Microsoft pasa a obtenerse desde Mojang, eliminando la dependencia de los servicios externos usados para mostrar la cabeza del personaje.

**Canal:** Estable · **Publicación original:** 2026-09-18 (UTC)

## Mejoras

- La textura se obtiene a partir del perfil de Minecraft y se recorta para mostrar la cabeza en la interfaz.
- Los fallos de un proveedor de avatares de terceros dejan de ser un requisito para mostrar la skin.

## Compatibilidad y límites

- La primera consulta necesita acceso al perfil y a las texturas de Mojang; este cambio no añade un editor de skins.
