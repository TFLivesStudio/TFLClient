Mods, resource packs y shaders separan la gestión de archivos instalados de la búsqueda de contenido; Linux incorpora un instalador de un comando.

**Canal:** Estable · **Publicación original:** 2026-09-23 (UTC)

## Novedades

- Pestañas Gestionar y Descargar, con selección múltiple, contenido popular, filtros de categoría y elección de versión.
- Modo Automático para evitar diálogos de archivo y modo Manual para habilitar iconos, fondos y contenido desde archivos locales.
- Script de instalación para Linux que detecta el sistema y elige entre paquetes DEB, RPM o AppImage.

## Al actualizar

- El modo de diálogos se elige en el primer uso y puede cambiarse en Ajustes. El script de Linux requiere curl.

## Compatibilidad y límites

- El modo Manual habilita diálogos nativos; no debe interpretarse como garantía de que el problema de macOS ya estuviera corregido en esta versión.
