El canal estable recibe la corrección de Java que evita cierres de instancias Vanilla antiguas en Mac con Apple Silicon.

**Canal:** Estable · **Publicación original:** 2026-10-19 (UTC)

## Correcciones

- El launcher detecta las versiones antiguas que no disponen de la combinación nativa esperada y utiliza la arquitectura de Java compatible.
- Se evita el arranque con bibliotecas nativas incompatibles que podía terminar con código de salida 255.

## Compatibilidad y límites

- El ajuste se dirige a las instancias Vanilla antiguas en Apple Silicon. No constituye una validación de todos los loaders o mods de esas versiones.
