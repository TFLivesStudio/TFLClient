Se incorpora TFL MP Guard para restringir las opciones multijugador de los perfiles sin conexión en la combinación de Minecraft y loader cubierta por esta entrega.

**Canal:** Estable · **Publicación original:** 2026-09-18 (UTC)

## Novedades

- El launcher incorpora el mod de protección al iniciar una instancia compatible con un perfil sin conexión.
- El mod deshabilita las opciones Multijugador y Abrir a LAN cuando recibe la indicación del launcher. No se activa para las cuentas de Microsoft.

## Compatibilidad y límites

- El recurso incluido corresponde a Minecraft 1.21.1 con Fabric. No hay una cobertura equivalente documentada para todas las versiones, Vanilla, Forge o NeoForge.
- La compilación del mod está documentada; el registro de esta entrega no acredita una prueba visual dentro de una partida real.
