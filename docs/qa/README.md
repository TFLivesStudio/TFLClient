# Evidencia histórica

`visual-refresh/` conserva las capturas y resultados que ya estaban versionados
en `artifacts/visual-refresh/`. Los archivos se trasladaron sin volver a generar
los resultados ni modificar las imágenes.

Las suites de navegador continúan escribiendo en `artifacts/`, que está ignorado
por Git y se publica como artefacto de CI. Esta carpeta conserva evidencia
seleccionada; no sustituye las comprobaciones de una compilación nueva.
