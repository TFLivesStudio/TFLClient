# Historial de documentación

- `legacy/` conserva los 46 archivos de changelog y notas de sesión que antes
  estaban en la raíz. Se han trasladado sin modificar su contenido.
- [Notas originales de GitHub](release-notes-before-2026-11-13.json): copia de las
  descripciones anteriores a la revisión del 13 de noviembre de 2026.
- [Registro de traslados](relocations.json): ruta anterior, nueva ruta y objeto Git
  de cada archivo trasladado. Permite comprobar que se conservaron sus bytes.

Estos documentos reflejan distintas etapas de desarrollo. Las limitaciones o
instrucciones antiguas no sustituyen las notas de la versión que se vaya a usar.
Las publicaciones revisadas están en [docs/releases](../releases/README.md).
