# Instaladores heredados

`installers/legacy/` conserva los seis archivos que antes estaban en `nuevo/`.
Se han trasladado sin modificar sus bytes ni volver a compilarlos.

La fuente de descargas vigentes son las
[releases de TFL Client](https://github.com/TFLivesStudio/TFLClient/releases) y la
[web oficial](https://launcher.tflives.com/descargas). Este archivo histórico no
interviene en la compilación ni en el sistema de actualizaciones.
