crates/aqua/src/utilities/mod.rs
  + fetch_text_retrying(url) -> Result<String, AquaError>
  + fetch_json_retrying<T>(url) -> Result<T, AquaError>
    GET con 3 reintentos, backoff exponencial (200ms * 2^n).

crates/aqua/src/downloaders/fabric.rs
  - resolve_latest_loader(): reemplazado HTTP_CLIENT.get(...).send()/.json()
    sin reintento por fetch_json_retrying().
  - new(): reemplazado fetch de perfil sin reintento por fetch_text_retrying().

crates/aqua/src/downloaders/quilt.rs
  - resolve_latest_loader() y new(): mismo cambio que fabric.rs.

crates/zellkern/src/manifest.rs
  - Library::is_correct_arch(): agregado caso has_generic_platform
    (classifier "natives-macos"/"natives-linux"/"natives-windows" sin
    sufijo de arquitectura). Antes caía en `true` incondicional para ese
    caso (se incluía siempre sin importar arquitectura del host). Ahora
    retorna `ARCH != "aarch64" && ARCH != "arm"`.
    Efecto: en hosts arm64 (Apple Silicon, Linux ARM, Windows ARM), ya no
    se descargan/extraen simultáneamente la build x86_64 genérica y la
    build arm64 de cada librería nativa de LWJGL (antes ambas jars
    escribían un archivo interno con el mismo nombre en natives_dir,
    pisándose entre sí de forma no determinística).
  - Tests existentes (25) verificados sin regresión: cargo test -p zellkern.

src-tauri/src/core/http_client.rs
  + get_text_retrying(url) -> Result<String, String>
  + get_json_retrying<T>(url) -> Result<T, String>
  + get_bytes_retrying(url) -> Result<Vec<u8>, String>
    Mismo patrón de reintento que aqua::utilities, para el cliente HTTP
    del lado src-tauri (const MAX_RETRY_ATTEMPTS: u32 = 3).

src-tauri/src/core/mod.rs
  - Export actualizado: pub use http_client::{HTTP, get_bytes_retrying,
    get_json_retrying, get_text_retrying}.

src-tauri/src/commands/loaders.rs
  - get_forge_version(): HTTP.get(...).send()/.json() reemplazado por
    get_json_retrying().
  - get_neoforge_version(): HTTP.get(...).send()/.text() reemplazado por
    get_text_retrying().

src-tauri/src/commands/versions.rs
  - get_available_versions(): fetch del manifest de Mojang reemplazado
    por get_json_retrying().

src-tauri/src/commands/mods.rs
  - search_mods(): reemplazado por get_json_retrying().
  - best_version(): reemplazado por get_json_retrying().
  - version_by_id(): reemplazado por get_json_retrying().
  - ModrinthFile: agregado campo `hashes: Option<ModrinthFileHashes>`.
  + struct ModrinthFileHashes { sha1: Option<String> }
  - download_mod_file(): reemplazado fetch de bytes sin reintento
    (HTTP.get().send()/.bytes()) por loop de hasta 3 intentos usando
    get_bytes_retrying(), con verificación SHA1 contra
    file.hashes.sha1 (cálculo vía sha1::Sha1::digest + formateo hex
    manual). Si el hash no coincide, reintenta la descarga completa;
    si los 3 intentos fallan, retorna error con detalle.
