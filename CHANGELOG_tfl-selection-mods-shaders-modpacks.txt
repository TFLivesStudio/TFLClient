TFL CLIENT — CHANGELOG: TFL Selection + shaders/modpacks por instancia
================================================================================

crates/cubrinth/src/mrpack/pack_format.rs
  - MrpackMetadata: nuevo campo `installed_paths: Vec<String>` (rutas
    relativas a instance_dir de cada archivo escrito). Vacío en
    parse_mrpack, poblado en install_mrpack.

crates/cubrinth/src/mrpack/installer.rs
  - install_mrpack(): ahora colecciona las rutas de los archivos
    declarados (mods) + las de los overrides extraídos, y las guarda en
    metadata.installed_paths.
  - extract_overrides(): firma cambiada de `Result<(), MrpackError>` a
    `Result<Vec<String>, MrpackError>` — devuelve la lista de rutas
    relativas que escribió.

src-tauri/src/commands/mods.rs (generalizado, antes solo mods)
  + enum ContentKind { Mod, Shader } — project_type de Modrinth, subdir
    de destino (mods/ vs shaderpacks/), y si filtra por loader (shaders
    no).
  - search_content(), best_version(), download_content_file(),
    install_recursive(): generalizadas con parámetro `ContentKind`.
    ModrinthVersion/ModrinthFile/ModrinthFileHashes/ModrinthDependency,
    best_version() y version_by_id() pasan a pub(crate) (los usa
    modpacks.rs).
  + search_shaders(query, mc_version) -> Vec<ModSearchHit>
  + install_shader(instance_name, project_id, mc_version)
  + get_instance_shaders(instance_name) -> Vec<String>
  + remove_shader(instance_name, filename)
  - search_mods/install_mod/get_instance_mods/remove_mod: firma sin
    cambios, ahora wrappers de las funciones genéricas.

src-tauri/src/commands/modpacks.rs (nuevo)
  + search_modpacks(query, mc_version, loader) -> Vec<ModSearchHit>
    (facets project_type:modpack + categories:<loader> + versions).
  + struct InstalledModpack { project_id, version_id, title, file_count }
  + install_modpack(instance_name, project_id, mc_version, loader):
    resuelve la mejor versión del modpack, baja el .mrpack a
    shared_dir/temp/, llama cubrinth::mrpack::install_mrpack(), guarda un
    manifest en instance_dir/.tfl_modpacks/<version_id>.json con
    installed_paths para poder desinstalar después.
  + get_instance_modpacks(instance_name) -> Vec<InstalledModpack> (lee
    .tfl_modpacks/*.json).
  + remove_modpack(instance_name, version_id): lee el manifest, borra
    cada archivo listado (path-traversal guardado con
    cubrinth::utils::path::safe_join) + el manifest.

Limitaciones documentadas, no resueltas en esta pasada
  - TFL Selection: lista hardcodeada de 1 entrada real (no hay backend/
    API propia de TFLives que la sirva — spec §26, insumo pendiente del
    cliente). Reemplazar `get_tfl_selection()` cuando TFLives entregue su
    lista curada.
  - Shaders: Modrinth no vincula shaders a un mod loader — la app no
    verifica ni instala automáticamente Iris/OptiFine, se documenta como
    requisito manual en la UI.
  - Progreso de descarga de modpacks: install_modpack no reporta progreso
    granular al event bus todavía (pasa `None` como progress channel) —
    la barra de descargas no muestra el avance de un modpack grande.
