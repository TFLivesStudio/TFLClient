CÓMO PUBLICAR UNA VERSIÓN REAL (la que el auto-update va a detectar)
================================================================================
El auto-update SOLO revisa Releases reales, no los artifacts de
workflow_dispatch. Para publicar una versión que los usuarios reciban
como actualización:

  1. Subir "version" en src-tauri/tauri.conf.json (ej. "0.1.0" → "0.2.0").
  2. Commitear ese cambio.
  3. git tag v0.2.0 && git push origin v0.2.0

Eso dispara el workflow con el tag, que esta vez SÍ crea el Release en
GitHub con los instaladores firmados + latest.json. Los launchers ya
instalados (con el botón "Buscar actualizaciones" en Ajustes → General)
van a detectar esa versión y podrán bajarla e instalarse solos, sin que
nadie tenga que ir a descargar nada a mano.

Los builds de prueba (workflow_dispatch, lo que uso normalmente para
pasarte links durante el desarrollo) NO quedan visibles para el
auto-update — siguen siendo solo artifacts privados de 90 días, como
hasta ahora.
